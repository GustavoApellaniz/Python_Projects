# Python Projects

A collection of small Python programs developed while learning programming. Each folder contains a self-contained project focused on fundamental programming concepts, from basic syntax to object-oriented programming.

The goal of this repository is to practice, experiment, and document my progress as I develop my Python skills.

## 📚 Topics Covered

- **Python Fundamentals:** Variables, data types, input/output, f-strings, and functions.
- **Conditionals:** Using `if`, `elif`, and `else` to control program flow.
- **Loops:** Using `while` and `for` loops, including counters and accumulators.
- **Object-Oriented Programming (OOP):** Classes, objects, attributes, and methods.
- **Error Handling:** `try`/`except`, input validation, raising exceptions, and custom exception classes.
- **Practical Applications:** Small programs combining multiple programming concepts.

## 📁 Repository Structure

Each project is organized into its own folder and contains one or more Python files that can be run independently.


## 🛠️ Concepts in Practice

Depending on the project, the code may demonstrate:

- `while` loops, counters, and accumulators
- Conditional statements
- Custom exception classes
- `try`/`except` blocks
- f-strings for formatted output

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project folder you want to explore:

   ```bash
   cd Python_Projects
   ```

3. Run a Python file:

   ```bash
   python main.py
   ```

   Replace `main.py` with the appropriate filename. Some projects may require additional navigation into their respective folders.

**Prerequisite:** Python installed on your system. The required Python version and any additional dependencies should be checked for each project.
